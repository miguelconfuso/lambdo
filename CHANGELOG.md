# Changelog

All notable changes to Lambdo are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Reproducible interference comparison in text and JSON formats.
- Repository preview, bilingual project presentation and contributor documentation.

## [0.1.0] - 2026-08-22

### Added

- Animated travelling-wave laboratory.
- Live amplitude, wavelength, frequency, phase and time controls.
- Two-wave interference and resultant superposition views.
- Constructive, destructive, partial and cancelled classifications.
- Phase rails, intensity indicator and contextual Learn mode.
- Live equation and derived-quantity inspectors.
- Deterministic snapshot mode.
- Mathematical and renderer invariant tests.
- Continuous integration for tests, type checking and production builds.

### Changed

- Replaced the original UI framework with a direct ANSI renderer.
- Added changed-region rendering, output backpressure and bounded animation frequency.
- Reduced the production bundle to approximately 19 KB with no runtime dependencies.
